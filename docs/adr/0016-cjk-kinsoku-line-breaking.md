# ADR 0016：CJK 禁则的可配置行首/行尾规则

- 状态：已接受
- 日期：2026-10-25

## 背景

CJK 排版有禁则（kinsoku）要求：行首不得出现句号、逗号、右括号等收尾标点，行尾不得出现左括号、左引号等开口标点。Weft 有两条分行路径：

1. 整段路径（无 Float）：交给 `TextPainter`/ICU 按整段文本分行。ICU 遵循 UAX #14 的断行类别（如 CL/IN 不得出现在行首、OP 后不可断行），天然满足禁则。
2. 逐行路径（存在 Float 排除区）：`buildLines` 用 `maxLines: 1` 的探测 painter 逐行测量，再以 `getPositionForOffset`/`getLineBoundary` 反推行末偏移，并叠加行首空白跳过、行尾空白裁剪、`\n` 吞并等启发式。该路径的断点不保证落在禁则安全位置（例如断点恰好在空格之后、下一行以全角标点开头，或紧急断行落在标点前），且禁则规则此前对宿主不可配置。

## 决策

### 规则表

- 新增 `WeftLineBreakRules`（`line_break_rules.dart`）：`lineStartProhibited`（行首禁则）与 `lineEndProhibited`（行尾禁则）两个 `Set<int>`，以 UTF-16 code unit 存储，便于用 `String.codeUnitAt` 直接查询。
- 默认表覆盖常用中日文标点。行首禁则：`。`（U+3002）、`、`（U+3001）、`，`（U+FF0C）、`．`（U+FF0E）、`：`（U+FF1A）、`；`（U+FF1B）、`？`（U+FF1F）、`！`（U+FF01）、`）`（U+FF09）、`〉`（U+3009）、`》`（U+300B）、`」`（U+300D）、`』`（U+300F）、`】`（U+3011）、`〕`（U+3015）、`…`（U+2026）、`—`（U+2014）、`・`（U+30FB）、`゛`（U+309B）、`゜`（U+309C）、`]`（U+005D）。行尾禁则：`（`（U+FF08）、`〈`（U+3008）、`《`（U+300A）、`「`（U+300C）、`『`（U+300E）、`【`（U+3010）、`〔`（U+3014）。
- `WeftLineBreakRules.off` 提供两张空表的 const 实例，关闭全部禁则调整，行为与旧引擎完全一致。
- 规则通过 `WeftLayoutEngine.layout` 的可选参数 `lineBreakRules`（默认 `const WeftLineBreakRules()`）传入，由 `_LayoutContext` 持有并透传给逐行路径。整段路径不消费该参数。

### 逐行路径的调整算法

在 `buildLines` 算出本行结束偏移 `consumed` 之后、既有 `\n` 吞并逻辑之前插入有界调整循环：

- 若下一行首个有效字符（跳过断点处的半角空格/Tab；`white-space: pre` 不跳）属于行首禁则表，则把断点前一个字符带到下一行；
- 否则若本行末字符属于行尾禁则表，则把它推到下一行；
- 循环直到两个条件都不满足、断点退到保底线（本行至少保留一个字符，代理对不拆开），或达到 64 次上限。

两点设计说明：

- 断点后紧跟空格再接禁则标点时，仅回退一个字符无效——行首空白跳过会把空格略过、禁则标点仍在行首，因此扫描会跨越空格串确认"有效行首字符"，必要时连空格一起回退（空格随后被行尾裁剪或行首跳过吸收，不产生可见差异）。
- 保底线保证整行都是禁则字符（如连续省略号）时每行仍至少前进一个字符：不会死循环，也不丢字。相邻硬换行（`\n`）后的禁则字符不强行回拉，与既有 `\n` 吞并逻辑保持兼容。

### 两路径对照结论

对照测试（整段纯中文标点文本，逐行以 `getLineBoundary` 切分检查）记录了 ICU 现状：整段路径行首/行尾禁则违规数均为 0，即 ICU 已通过 UAX #14 断行类别满足禁则，整段路径无需另行调整。逐行路径因探测启发式不保证等价，才需要显式规则；两条路径的差异以此 ADR 与对照测试记录为现状基线。

## 后果

- 逐行路径的行首/行尾禁则由显式、可配置的规则表保证，并有测试覆盖默认表、空表、全禁则字符行与自定义表四种情形。
- 调整只会让断点回退（本行内容变短），不会让 painter 文本超出可用行宽；逐行文本拼接仍完整覆盖原文（对比忽略断点处折叠的空白）。
- 已知边界：保底单字符行可能违反禁则（排版上不可再退）；断点跨越空格串的回退上限 64 次；表以 code unit 匹配，不含代理对字符，组合字符（基字+符号）不做簇级处理。
- 未来如需支持 `line-break: loose/strict` 或行尾标点悬挂，可在 `WeftLineBreakRules` 上扩展，不动分行循环结构。
