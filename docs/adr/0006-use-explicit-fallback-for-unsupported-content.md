# ADR 0006：不支持内容必须显式回退

- 状态：已接受
- 日期：2026-10-25

## 背景

让引擎无限吸收 Canvas、完整 DOM 和复杂 Web 应用会违背轻量定位；静默忽略这些能力又会造成错误内容呈现。

## 决策

规范化和解析阶段输出 `SupportReport`。不支持内容由 `WeftView.fallbackBuilder` 交给宿主处理，未提供回退时明确失败。核心不直接依赖 `webview_flutter`。

## 后果

该方案保持核心轻量并让能力边界可见，代价是宿主需要实现回退策略。任何新能力都必须评估是否应由专用库或 WebView 承担，而不是默认进入引擎路线图。
