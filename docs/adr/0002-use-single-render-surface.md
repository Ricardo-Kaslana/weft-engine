# ADR 0002：采用单一 RenderObject 渲染表面

- 状态：已接受
- 日期：2026-10-25

## 背景

逐标签创建 Widget 会增加长文档树规模、布局和状态管理成本，也难以统一实现浮动、跨段选择和分块绘制。

## 决策

文档内容由一个 `RenderWeftSurface` 承载，内部管理 Fragment、Picture、命中、选择和语义。自定义标签默认通过布局/绘制契约扩展，而不是任意插入 Widget。

## 后果

该方案降低长文档 Widget 开销并统一交互，但需要自行实现选择、语义和手势。上述能力必须作为早期竖切验收，不能留到发布后补做。当前骨架只有渲染表面，实际绘制尚未实现。
