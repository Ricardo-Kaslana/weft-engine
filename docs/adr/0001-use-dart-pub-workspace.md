# ADR 0001：采用 Dart Pub workspace

- 状态：已接受
- 日期：2026-10-25

## 背景

项目包含公开 API、纯 Dart 文档模型、Flutter 引擎、Runtime 抽象和多个可替换实现，需要清晰依赖边界与统一依赖解析。

## 决策

采用 Dart Pub workspace 管理包，不额外引入 Melos 等 monorepo 工具。所有包在根目录解析依赖，`tool/verify.dart` 提供统一测试入口。最低 Dart 版本设为 3.5。

## 后果

优点是减少工具依赖、路径依赖明确、CI 简单。代价是依赖 Dart 3.5+，跨包命令需要仓库自有脚本维护。若未来工作区能力无法满足发布需求，可新增任务编排工具，但不得改变包依赖方向。
