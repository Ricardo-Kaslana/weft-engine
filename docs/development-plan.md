# 开发里程碑

每个阶段必须交付可运行示例、测试证据、架构更新、性能记录和 ADR。上一阶段的 S0/S1 缺陷未关闭，不进入下一阶段。

## 阶段 0：工程初始化（已完成）

交付 Pub workspace、包边界、公开契约、渲染表面、Runtime 适配边界、实验室、基础测试和项目文档。

验收：依赖可解析、格式化与静态检查通过、全部基础测试通过、CI 可复现。此阶段不宣称 HTML 或 JS 功能完成。

当前证据：Flutter 3.35.5 / Dart 3.9.2 下静态分析无问题，workspace 测试与 CI 入口可运行。

## 阶段 1：规范基线与静态渲染（进行中）

原目标为规范化器、HTML/CSS 解析适配、计算样式、Block/Inline/List、链接、基础文本和分块绘制。按 ADR 0007，阶段 1A 先交付直接布局和完整绘制命令，分块 Picture 与视口绘制移至阶段 3 的性能工作。

### 1A：基础静态渲染（已完成）

已交付：

- 受控 HTML 树、标签/属性过滤、节点和输入限制、结构化诊断。
- 结构化 CSS 选择器、特异性层叠、继承、内联样式及 margin/padding 简写展开。
- 标题、段落、行内强调、链接样式、列表、引用、代码、分隔线和换行。
- 单渲染表面、滚动入口、真实背景/文本绘制、文本缩放和资源释放。
- 空白折叠、基础 margin 折叠、窄宽度换行、CJK 与 300 段长文档测试。

当前明确未完成：浏览器黄金对照、链接点击、图片/表格、Float/CJK 禁则、性能基线和分块绘制。图片、表格和复杂元素当前按支持度报告回退，不宣称完整支持。

### 1B：阶段 1 收尾

仍需完成：

- 固定字体、视口和 DPR 的 Chromium 对照语料与黄金门禁。
- 基础宽高、边框等已列入阶段 1 的样式，或正式从子集移出并更新矩阵。
- 静态文章、商品描述和帮助文档的代表性语料验收。
- 与功能等价“标签→Widget”方案的首次解析和布局性能基线。
- 对内容丢失、重叠、越界和异常诊断做端到端检查。

阶段 1 门禁不能仅以“示例看起来正常”通过，需要提交批量语料与测量结果。

## 阶段 2：完整内容排版

实现图片资源、左右 Float、Clear、表格、CJK 禁则和布局失效。

主要验收：

- 跨段落环绕、图片晚加载、宽度变化、清浮动和表格跨距有黄金覆盖。
- 开闭标点和不可断内容具有边界测试。
- 缓存失效不会遗留浮动或文本测量结果。
- 所有目标用例无重叠、越界和静默缺失。

## 阶段 3：长文档、选择与性能

实现稳定全局文本索引、跨段选择、复制、可见区绘制、语义和滚动交互。

主要验收：

- 10 万字符参考文档上执行随机跨段选择和复制，无崩溃、代理对切断或内容错误。
- 文档更新后选区正确重映射或安全失效。
- 首次解析与布局核心耗时较等价 Widget 基线目标降低至少 40%。
- 参考设备滚动 P95 帧耗时不高于 16.7ms，P99 不高于 33.4ms。
- 连续滚动后缓存进入稳定预算，不随轮次线性增长。

## 阶段 4：受限 JS 与能力扩展

接入 QuickJS、单文档 Context、状态/事件/网络能力、资源中断和恢复；交付一个自定义标签和 FakeRuntime 契约示例。

主要验收：

- 无限循环和内存炸弹在配置预算内中断，UI 保留最后可用帧。
- 未启用能力不可见，白名单重定向和非法协议被拦截。
- 恢复不自动重放网络副作用，命令序号可去重。
- 后端替换不需要修改引擎核心。

## 阶段 5：回退、硬化与发布

完成服务端/客户端规范化一致性、WebView 回退示例、模糊测试、真机矩阵、API 文档和发布回退流程。

主要验收：全部门禁通过，发布产物版本兼容明确，JS 和单能力可独立关闭，回滚路径经过演练。

## 并行规则

CI、测试语料和文档从阶段 1 持续建设。Runtime 接口可提前用 Fake 验证，但具体业务集成不得绕过阶段 1–3 的正确性门禁。性能优化不得删除正确性测试或扩大允许误差。
